# Council of Veterinary Surgeons of Zimbabwe

## Local development

Install the project dependencies once, then start the local development server:

```sh
npm install
npm run dev -- --host 127.0.0.1
```

Open the local URL printed by Vite (by default, http://127.0.0.1:5173). Once
dependencies are installed, the site and its assets run locally without
requesting externally hosted fonts.
